A free, open-source **Visual Database Schema & ER Diagram Designer** built to run 100% in your browser — no sign-up, no backend, no subscriptions. Design relational databases visually on an infinite canvas, connect tables with live foreign-key curves, import existing SQL, and export production-ready code in seconds.

## Live Demo
👉 **[Launch SchemaForge Studio Live](https://a1n2a3s6.github.io/schemaforge-studio/)**

## Key Features
- **Infinite Pan & Zoom Canvas:** Smooth drag-and-drop table nodes with live 60fps SVG Bezier relationship curves and cardinality markers (`1:1`, `1:N`, `N:M`).
- **Drag-to-Connect Foreign Keys:** Link columns visually across tables or configure constraints (`PK`, `FK`, `Unique`, `Not Null`, `Default`) in the inspector.
- **Multi-Dialect Code Generation:** Instantly generate and download clean schemas for **PostgreSQL**, **MySQL**, **SQLite**, and **Prisma Schema**.
- **SQL DDL Importer:** Paste existing `CREATE TABLE` SQL statements to reverse-engineer an interactive visual diagram automatically.
- **Ready-to-Use Templates:** Start fast with built-in schemas for *SaaS Auth & Billing*, *E-Commerce Store*, and *Social Media App*.
- **Export Anywhere:** Download your architecture as **SVG**, high-resolution **PNG**, or **JSON** project backups — plus full Undo/Redo and `localStorage` autosave.

## Built With
- HTML5 & SVG Graph Engine
- Vanilla JavaScript (Custom SQL Parser & Multi-Dialect Generator)
- Tailwind CSS (CDN)
